# Tioluwani Akinloye's Portfolio (Version 2)

Welcome to my portfolio (again)! This document provides an overview of the portfolio website, including its features, technologies.

## Overview

This portfolio is designed to showcase the skills, projects, and experiences of Tioluwani Akinloye, a software and AI/ML engineer working toward robotics, computer vision, and intelligent systems. The website utilizes React, TypeScript and Vite, with hand-written CSS and Lucide for icons.

Deployed on Netlify: https://tioluwaniportfolio.netlify.app

Previous version: https://tioluwaniportfoliolegacy.netlify.app

## Cool Features

- Boot Sequence (a short system-startup animation on your first visit each session, skippable with Enter or Esc)
- Tracking Cursor (crosshairs that follow your mouse and lock onto and explain elements and their purposes)
- Visitor Signal Readout (gives you information about your own location, local time, device, and where you came from)

### Sections

- **Homepage**:
  - Introduces me with a brief description, a live visitor readout, and buttons to get in touch or download my resume.

- **Profile**:
  - Offers a short biography, including educational background, personal interests, and location.

- **Projects**:
  - Showcases my projects as case files, each with its own page covering the problem, approach, result, technologies, and an architecture diagram, plus links to view them live or on GitHub.

- **Experiences**:
  - Highlights my professional, research, teaching, and educational experiences on a timeline.

- **Skills**:
  - Displays my technical skills with icons, grouped into languages, frameworks, cloud and infrastructure, and ML and databases.

- **Contact**:
  - Provides multiple ways to get in touch including email, GitHub, LinkedIn, and a contact form for direct communication.

## Technologies Used

- **React**: Utilized for interactive components and managing state within the portfolio.
- **TypeScript**: Adds types to the components and the project, timeline, and skills data.
- **Vite**: Dev server and production build.
- **React Router**: Routes between the home page and individual project pages.
- **CSS**: Used for styling, with external stylesheets (`base.css`, `layout.css`, `sections.css`) to customize the look and feel.
- **EmailJS**: Sends messages from the contact form.
- **Lucide**: Icon library for buttons and other icons.
